🚀 **LLM Routing with a Unified API | CrewAI + DeepRelay**

Built a Smart Agent that routes tasks to suitable LLMs using the **DeepRelay Unified API**.

Instead of manually selecting a model for every request, the application uses task keywords and complexity to choose a suitable text or image model, with fallback options if a model fails.

🔹 **LLM Routing:** Directs each task to a suitable model based on its requirements.

🔹 **Unified API:** Provides access to multiple AI models through a single API endpoint and API key.

🔹 **Key Advantages:**
- One API integration for multiple models
- Automatic model selection based on task type
- Access to text and image generation models
- Flexible fallback between models
- Simplified integration and model management

🛠️ **Tech Stack:** Python | Streamlit | CrewAI | DeepRelay Unified API

The goal is simple: **One API, multiple models, smarter task execution.**
